# 问题手册

给自己用的处置经验库。把处理过的问题、当时的回复方法和截图存下来，下次遇到同类问题，搜一下就能看到上次是怎么答的。

纯静态网页，不需要服务器、不需要安装、不上传任何数据。数据只存在你自己浏览器的本地数据库里。

---

## 能做什么

- **登记问题**：标题、发生日期、分类、客户/供应商、**会话 ID**、**电话**、处理状态、标签
- **问题描述 + 截图**：支持拖拽图片、直接 `Ctrl+V` 粘贴截图，粘贴到哪一侧就进哪一侧
- **解决方法 + 截图**：步骤化记录，一键复制回复话术
- **快速检索**：搜索标题、描述、解决方法、客户、标签、**会话 ID**、**电话**，按相关度排序
- **筛选**：按分类、状态（含「待跟进」）、重点标记过滤
- **登记提醒**：上班时页面常开，到点提醒你记一笔（可设间隔和工作时间）
- **待跟进提醒**：每天第一次打开时，提示还没处理完的记录
- **导入旧表格**：`.xlsx` / `.xls` / `.csv`，自动识别列名，导入前可预览和手动校正
- **导出**：完整备份（含图片的 JSON）、Excel 可读的 CSV
- **重点标记与使用计数**：常看的问题置顶，详情页会自动记录被查看的次数

## 会话 ID 和电话

客服场景里最常用的是「拿会话 ID 反查当时怎么处理的」：

- 详情页里点一下会话 ID 或电话号码，直接复制到剪贴板
- 搜索框输入会话 ID 片段（比如 `S20261108`）就能命中
- 会话 ID 的匹配权重最高，搜索结果会排在最前面

如果你有旧数据的「来源渠道」字段，编辑那条记录时会多出一个「原来源渠道」框，保留历史信息，不需要的话清空即可。

## 怎么用起来

### 推荐：部署到 GitHub Pages

1. 在 GitHub 上新建一个仓库（建议设为 Private，数据在你本地，仓库只是代码）
2. 把本目录下的这些文件和文件夹传上去：

```
index.html
README.md
.nojekyll
assets/
  css/style.css
  js/app.js
  js/db.js
  js/importer.js
  vendor/xlsx.full.min.js
```

3. 仓库 **Settings → Pages → Source** 选 `main` 分支、`/ (root)` 目录，保存
4. 等一两分钟，访问 `https://你的用户名.github.io/仓库名/`
5. 把这个网址收藏到浏览器书签栏，以后一键打开

命令行推送（把地址换成你自己的仓库）：

```bash
git init
git add .
git commit -m "初始化问题手册"
git branch -M main
git remote add origin https://github.com/你的用户名/你的仓库名.git
git push -u origin main
```

### 本地查看

```bash
python -m http.server 8000
```

然后打开 <http://localhost:8000>。

> 不要直接双击 `index.html` 打开。`file://` 协议下浏览器可能禁用本地数据库，导致无法保存。必须通过 http 访问。

## 数据存在哪里

数据保存在**当前浏览器的 IndexedDB** 里，按域名隔离：

- 同一个浏览器、同一个网址 → 数据都在
- 换浏览器（Chrome 换 Edge）、换电脑、换网址 → 看不到原来的数据
- 清理浏览器「Cookie 和其他网站数据」→ 数据会丢失

所以建议**每月导出一次完整备份**：设置与备份 → 导出完整备份（.json）。换设备后在新的设备上恢复即可。

⚠️ 备份文件里包含你的原始照片，不要提交到公开仓库，也不要随手发到群里。

## 导入旧表格

支持 `.xlsx`、`.xls`、`.csv`，会自动尝试匹配表头。

> 第一次点开「导入表格」时，页面要临时加载一个表格解析组件（约 340KB，视网络 3～10 秒），页面上会显示加载提示。加载一次后浏览器会缓存，之后再打开基本是瞬间的。

能识别的常见写法包括：

| 字段 | 能识别的表头举例 |
|---|---|
| 问题描述 | 问题描述、问题、问题现象、客户反馈、故障描述、具体问题 |
| 解决方法 | 解决方法、处理方式、怎么处理、回复话术、解决方案、处理结果 |
| 发生日期 | 日期、时间、登记日期、处理日期 |
| 客户 | 客户、客户名称、供应商、门店 |
| 会话 ID | 会话ID、会话编号、工单号、对话ID |
| 电话 | 电话、手机号、联系电话、电话号码 |
| 分类 | 分类、问题类型、类别 |
| 标签 | 标签、关键词、关键字 |
| 照片 | 问题照片、截图、图片链接 |

- 日期支持 `2026/3/5`、`2026-03-05`、`2026年3月5日`、Excel 日期格式
- 中文 CSV（GBK 编码）可以正常读取，不会乱码
- 标题列没填时，会自动用问题描述前 30 字生成
- 重复记录（标题 + 问题描述相同）会自动跳过，同一个文件可以放心多导几次
- 照片列如果是链接或文件名，会保留成文字附在描述后面；图片本身需要导入后单独补传

## 登记提醒怎么用

点击右上角的铃铛，会跳到设置里的提醒卡片：

1. 打开「开启定时提醒」
2. 选间隔（30 分钟到 2 小时）
3. 设工作时间（默认 9:00–18:00，只在时间段内提醒）
4. 到点后右下角弹提示，点「去登记」直接进登记页；点「稍后 15 分钟」就推迟

提醒只在页面打开且处于前台时触发，正在编辑时不会打断你。勾了「标签页标题闪烁」的话，即使切到别的窗口，标签上也会闪 `⏰ 该登记了`。

另外，每天第一次打开时会看到一条黄色提示，告诉你还有几条记录没处理完，点「去查看」直接筛出这些记录，点 × 当天就不再提示。

## 几个使用建议

- **标题写「现象 + 结论」**，比如「会员卡余额不同步，顾客要求退款」，以后扫一眼就认得出
- **解决方法按步骤写**，带上后台菜单路径，可以直接复制给同事
- **常用的问题打星**，会在列表里置顶
- 分类可以自己加：设置与备份 → 分类管理

## 技术说明

- 纯 HTML / CSS / JavaScript，无框架、无构建步骤、无后端
- Excel 解析用 [SheetJS](https://sheetjs.com/)，已放在本地 `assets/vendor/`，断网也能用
- 图片保存前自动压缩：主图长边 1680px、缩略图 360px，避免占用过多空间
- 兼容 Chrome / Edge 最新版本（IndexedDB + ES2020）
